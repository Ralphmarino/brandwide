Mouseflow sync

This Mouseflow plan has no usable public API, so the Behaviour report is fed by a snapshot you take from inside Mouseflow. Run it whenever you want the report refreshed — once a week is plenty.

What it collects

  

    

      

        

          
            
DataDetail

          
          
            

              Daily aggregates
              Sessions, visitors, pageviews, average visit and engagement
                  duration, and friction score — for the last 90 days.
            

            

              Breakdowns
              Daily session counts by device type, entry page, country,
                  referrer type and browser.
            

            

              Recent recordings
              The latest 25, with IP, latitude, longitude, city and visitor
                  ID stripped before anything leaves the browser.
            

            

              Top pages
              The top 10 by views.
            

          
        

      

    

  


  

    Mouseflow only retains about 90 days. Every sync adds to the stored
    history rather than replacing it, so once you have been syncing for a while
    the report can look back further than Mouseflow itself can.
  


  
If something goes wrong

  

    

      

        

          
MessageWhat to do

          
            

              Could not read a CSRF token
              You are not signed in to Mouseflow in that tab, or the session
                  expired. Reload and sign in.
            

            

              The ingest secret was rejected
              The stored secret is cleared automatically. Run it again and
                  paste the correct value.
            

            

              Run this on us.mouseflow.com
              The bookmarklet only works on the Mouseflow origin, because it
                  relies on your logged-in session there.
            

            

              Mouseflow returned HTTP 4xx
              The internal endpoint has probably changed. Nothing is written
                  when this happens — the stored history is untouched.
