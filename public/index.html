How to connect each source

Google Analytics 4

1. Create a service account

In Google Cloud Console, create a project, enable the Google Analytics Data API, then create a service account and download its JSON key.

2. Grant it access

In GA4 → Admin → Property access management, add the service account email as a Viewer.

3. Set the variables

  • GOOGLE_CLIENT_EMAIL
  • GOOGLE_PRIVATE_KEY
  • GA4_PROPERTY_ID — the numeric ID

Search Console

1. Enable the API

Enable the Google Search Console API in the same Cloud project. The same service account is reused.

2. Add the user

In Search Console → Settings → Users and permissions, add the service account email with Full or Restricted access.

3. Set the variable

  • GSC_SITE_URL — either sc-domain:brandwide.com or the exact URL-prefix property

Search Console finalises data about 2–3 days behind, so the most recent days may look light.

Mouseflow

1. Create an API key

In Mouseflow, open Settings → API Keys and generate a key. Note the region shown there (US or EU).

2. Set the variables

  • MOUSEFLOW_USERNAME — your login email
  • MOUSEFLOW_API_KEY
  • MOUSEFLOW_REGION — us or eu
  • MOUSEFLOW_WEBSITE_ID — optional

3. What you get

Mouseflow's API serves recordings and heatmaps rather than aggregate metrics, so this panel reports recording volume, device split, entry pages and friction scores, and deep-links into Mouseflow for playback.

Notes

Every variable is set in Netlify under Site configuration → Environment variables. Credentials are only ever read inside the serverless functions — they are never sent to the browser.

Any source without credentials renders clearly-labelled sample data so the dashboard stays explorable while connections are being arranged.
